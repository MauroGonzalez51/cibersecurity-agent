\subsection*{Variables de Entorno Requeridas}

Para el correcto funcionamiento del sistema, es necesario definir las siguientes variables de entorno en un archivo \texttt{.env} en la raíz del proyecto:

\begin{itemize}
    \item \texttt{POSTGRES\_USER}: Usuario de la base de datos PostgreSQL\@{}.
    \item \texttt{POSTGRES\_PASSWORD}: Contraseña de la base de datos PostgreSQL\@{}.
    \item \texttt{POSTGRES\_HOST}: Host de la base de datos PostgreSQL\@{}.
    \item \texttt{POSTGRES\_PORT}: Puerto de la base de datos PostgreSQL (por defecto, 5432).
    \item \texttt{POSTGRES\_DB}: Nombre de la base de datos PostgreSQL\@{}.
    \item \texttt{OPENROUTER\_API\_KEY}: Clave de API para el servicio OpenRouter.
    \item \texttt{VIRUSTOTAL\_API\_KEY}: Clave de API para el servicio VirusTotal.
    \item \texttt{GEOIP\_DATABASE\_PATH}: Ruta al archivo de base de datos GeoLite2-City.mmdb (Opcional).
\end{itemize}
